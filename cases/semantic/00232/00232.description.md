# Test 00232

A ModelChange applied to the end state of a simulation: the change takes effect from there.

## Expected results

S(1) = 3 exp(-0.5) with k1 = 0.5.  Then k1 is set to 1 without touching the state, and one more time unit gives S(2) = S(1) exp(-1).

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
