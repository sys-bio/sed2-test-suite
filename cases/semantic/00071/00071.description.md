Logical operators and their call forms, each true: every result is 1.

- `and1`: `piecewise(1, 1 < 2 && 2 < 3, 0)` = 1.0
- `or1`: `piecewise(1, 1 > 2 || 2 > 1, 0)` = 1.0
- `not1`: `piecewise(1, !(1 > 2), 0)` = 1.0
- `and2`: `piecewise(1, and(1 < 2, 2 < 3, 3 < 4), 0)` = 1.0
- `or2`: `piecewise(1, or(1 > 2, 2 > 3, 3 < 4), 0)` = 1.0
- `xor1`: `piecewise(1, xor(1 < 2, 1 > 2), 0)` = 1.0 (exactly one true)
- `xor3`: `piecewise(1, xor(1 < 2, 1 < 3, 1 < 4), 0)` = 1.0 (an odd number are true)
- `not2`: `piecewise(1, not(2 < 1), 0)` = 1.0
- `imp1`: `piecewise(1, implies(1 > 2, 1 > 3), 0)` = 1.0 (false implies anything)
- `imp2`: `piecewise(1, implies(1 < 2, 2 < 3), 0)` = 1.0 (true implies true)
- `and0`: `piecewise(1, and(), 0)` = 1.0 (empty and is true)
- `t`: `piecewise(1, true, 0)` = 1.0
- `prec1`: `piecewise(1, 1 + 1 == 2, 0)` = 1.0 (+ binds tighter than ==)
- `prec2`: `piecewise(1, 1 == 2 && 1 == 1 || 1 == 1, 0)` = 1.0 (&& and || share a level, left to right: (false && true) || true)
- `prec3`: `piecewise(1, !(1 == 2) && 2 == 2, 0)` = 1.0
