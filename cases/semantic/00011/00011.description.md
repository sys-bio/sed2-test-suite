# Test 00011

Booleans are parsed numerically: true is 1 and false is 0.

## Expected results

The scalar is 1 and the vector is 1, 0, 1.

## Notes

The specification says booleans 'may be parsed numerically as 1 or 0', so this case tests the behaviour that is allowed, not one that is required.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
