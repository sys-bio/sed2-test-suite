# Test 00111

Concentration and volume: S has concentration 4 in a compartment of volume 2, and the rate k*S is in amount per time.

## Expected results

Amount n = 2 S, dn/dt = -k S = -(k/2) n, so n and [S] both decay with rate k/2 = 0.25: [S] = 4 exp(-t/4).  The compartment size stays 2.
