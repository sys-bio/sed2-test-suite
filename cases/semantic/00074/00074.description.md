# Test 00074

piecewise: the first condition that is true wins; the last lone argument is the 'otherwise' value.

## Expected results

- `first`: `piecewise(10, 1 > 2, 20, 2 > 1, 30, 3 > 2, 99)` = 20.0 (the second pair is the first true one)
- `other`: `piecewise(10, 1 > 2, 99)` = 99.0 (no condition is true)
- `noother`: `piecewise(5, 1 < 2)` = 5.0
- `only`: `piecewise(99)` = 99.0 (a lone argument is the otherwise value)
- `none`: `piecewise(5, 1 > 2)` = nan (no condition is true and there is no otherwise value: undefined (NaN))
- `calc`: `piecewise(2 * 3, 1 < 2, 0)` = 6.0 (values are expressions too)
- `nested`: `piecewise(piecewise(1, 1 > 2, 2), 1 < 2, 3)` = 2.0 (inner piecewise gives 2)

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
