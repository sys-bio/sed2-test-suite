# Test 00165

The Jacobian at the end state of a time course: 2 A -> B at rate 0.5 A^2 run until t = 2, from A = 2.

## Expected results

A(t) = A0/(1 + 2 k A0 t) = 2/(1 + 4) = 0.4 at t = 2.  Then dA'/dA = -4 k A = -0.8 and dB'/dA = 2 k A = 0.4.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
