# Test 00155

A non-linear steady state: production at rate 2 and removal at rate 0.5 S^2, from S = 1.5.

## Expected results

dS/dt = v - k S^2 = 0 gives S = sqrt(v/k) = sqrt(4) = 2 (the positive root, which the starting value 1.5 is near).

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
