# Test 00073

Comparisons with NaN are false except !=.

## Expected results

- `eq`: `piecewise(1, notanumber == notanumber, 0)` = 0.0
- `lt`: `piecewise(1, notanumber < 1, 0)` = 0.0
- `gt`: `piecewise(1, notanumber > 1, 0)` = 0.0
- `neq`: `piecewise(1, notanumber != notanumber, 0)` = 1.0
- `inf`: `piecewise(1, infinity > 1e300, 0)` = 1.0
- `ninf`: `piecewise(1, -infinity < -1e300, 0)` = 1.0

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
