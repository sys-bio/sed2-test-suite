# Test 00114

Second order: 2 A -> B with rate k A^2 and A(0) = 2, k = 0.5 (each reaction event uses two A).

## Expected results

The rate of the reaction is v = k A^2 and A is consumed twice per event, so dA/dt = -2 k A^2: A = A0/(1 + 2 k A0 t) and B = (A0 - A)/2.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
