# Test 00220

A Loop inside a Scatter, the loop's initial value taken from the outer range.

## Expected results

The inner loop doubles its variable three times starting from the outer range value r: 2r, 4r, 8r.  The last is 8r: 8 for r = 1 and 16 for r = 2.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
