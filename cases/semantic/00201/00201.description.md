# Test 00201

Scatter of a parameter sweep: the range value is set into the model, which is simulated for 2 time units.

## Expected results

S' = -k1 S from S = 3 gives S(2) = 3 exp(-2 k1) for k1 = 0.25, 0.5, 0.75, 1.  Each iteration starts from the original model, since the ModelChange is applied to the imported model, not to the previous result.

## Sign-off

- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
