# Test 00120

A stiff pair: x' = -1000 x and y' = -y + x, from x = 1, y = 0, sampled at points that span four decades.

## Expected results

x = exp(-1000 t).  y' + y = exp(-1000 t) has the particular solution -exp(-1000 t)/999, so with y(0) = 0: y = (exp(-t) - exp(-1000 t))/999.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
