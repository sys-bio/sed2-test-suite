# 00005

Full Jacobian of the chain A -> B -> (k1 = 1, k2 = 2) at its initial state (A = 1, B = 0.5; the Jacobian of this linear model does not depend on the state, and COPASI cannot differentiate with respect to a species whose value is 0, see disagreement D-001).  dA/dt = -k1 A and dB/dt = k1 A - k2 B, so the Jacobian is [[-1, 0], [1, -2]], rows and columns in the order A, B.
