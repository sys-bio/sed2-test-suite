# Test 00063

The six hyperbolic functions at x = ln 2, where e^x = 2 and e^-x = 1/2.

## Expected results

- `sinh`: `sinh(ln(2))` = 0.75 ((2 - 1/2) / 2)
- `cosh`: `cosh(ln(2))` = 1.25 ((2 + 1/2) / 2)
- `tanh`: `tanh(ln(2))` = 0.6 (0.75 / 1.25)
- `sech`: `sech(ln(2))` = 0.8 (1 / 1.25)
- `csch`: `csch(ln(2))` = 1.3333333333333333 (1 / 0.75)
- `coth`: `coth(ln(2))` = 1.6666666666666667 (1.25 / 0.75)
- `s0`: `sinh(0)` = 0.0
- `c0`: `cosh(0)` = 1.0

## Sign-off

- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
