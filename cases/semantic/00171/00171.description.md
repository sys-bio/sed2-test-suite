# Test 00171

JacobianReduced of a chain with one conservation law: A <-> B <-> C, A + B + C = 6.  The independent species are A and B.

## Expected results

C = 6 - A - B.  dA/dt = -k1 A + k2 B gives (-1, 0.5).  dB/dt = k1 A - k2 B - k3 B + k4 C = k1 A - (k2 + k3) B + k4 (6 - A - B) gives d/dA = k1 - k4 = 0.75 and d/dB = -(k2 + k3) - k4 = -2.75.
