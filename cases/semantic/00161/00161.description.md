# Test 00161

JacobianFull of a linear chain A -> B -> (k1 = 1, k2 = 2) at the initial state A = 1, B = 0.5.

## Expected results

dA/dt = -k1 A and dB/dt = k1 A - k2 B, so J = [[-k1, 0], [k1, -k2]] = [[-1, 0], [1, -2]] with rows and columns labelled A, B.  J[B, A] = dB'/dA = 1; the row B is (1, -2) and keeps the column labels.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi (agree within the tolerances; admitted 2026-10-09 by the suite runner; not supported by the translator: opencor).
