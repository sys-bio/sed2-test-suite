# Test 00099

StringFormation: numbers.  An integral number has no decimal point; any other is the shortest decimal that reads back the same.

## Expected results

3 -> 3, 2.5 -> 2.5, -2 -> -2, 0.1 -> 0.1, 100 -> 100.  The constant 3.0 is written 3.  1/3 needs sixteen digits to read back the same: 0.3333333333333333.  4.0 is written 4.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
