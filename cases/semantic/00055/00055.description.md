# Test 00055

The remainder, as an operator and as functions: the result has the sign of the dividend.

## Expected results

- `r1`: `7 % 3` = 1.0
- `r2`: `-7 % 3` = -1.0 (x - y * trunc(x / y) = -7 - 3 * (-2))
- `r3`: `7 % -3` = 1.0 (7 - (-3) * (-2))
- `r4`: `5.5 % 2` = 1.5
- `r5`: `rem(-7, 3)` = -1.0
- `r6`: `rem(7.5, 2)` = 1.5
- `q1`: `quotient(7, 2)` = 3.0 (integer part of 3.5)
- `q2`: `quotient(10, 5)` = 2.0
- `q3`: `2 + 7 % 4 * 2` = 8.0 (% binds like *: 2 + (7 % 4) * 2 = 2 + 6)

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
