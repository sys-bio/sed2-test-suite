# Test 00202

Scatter in which each iteration returns a whole time course: the result has the iterations, the entry, and then the table's own two dimensions.

## Expected results

For k1 = 1, 2, 3: A(t) = 3 exp(-k1 t) and B = 3 - A at t = 0, 0.25, 0.5, 0.75, 1.  The result has dimensions (iteration, entry, time point, column): 3 x 1 x 5 x 3; the table's columns keep their labels (time, A, B).

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
