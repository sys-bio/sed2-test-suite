# Test 00168

JacobianFull of a model with a conservation law: A -> B reversible, kf = 1, kr = 0.5, A = 2, B = 1.

## Expected results

dA/dt = -kf A + kr B and dB/dt = kf A - kr B give J = [[-kf, kr], [kf, -kr]] = [[-1, 0.5], [1, -0.5]], which is singular (A + B is conserved).
