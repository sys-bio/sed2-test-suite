# Test 00109

A reversible reaction A <-> B (kf = 1, kr = 0.5) from A = 1, B = 0, which has a conservation law A + B = 1.

## Expected results

A(t) = A_eq + (1 - A_eq) exp(-(kf + kr) t) with A_eq = kr/(kf + kr) = 1/3; B = 1 - A.  The output variables are listed in the order B, A and the columns follow that order.

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
