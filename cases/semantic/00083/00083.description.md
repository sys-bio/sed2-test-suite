# Test 00083

sum reduces the outermost dimension: a vector gives a number and a matrix gives a vector (column sums).

## Expected results

- `vec`: `sum(#constants:v)` = 150.0 (10 + 20 + 30 + 40 + 50)
- `mat`: `sum(#constants:m)` = [5.0, 7.0, 9.0] (rows 1 2 3 and 4 5 6 added together)
- `part`: `sum(#constants:v[1:4])` = 90.0 (20 + 30 + 40)
- `row`: `sum(#constants:m[1])` = 15.0 (4 + 5 + 6)
- `col`: `sum(#constants:m[0:2, 1])` = 7.0 (2 + 5)
- `expr`: `sum(#constants:v) / 5` = 30.0 (the mean)
- `sq`: `sum(#constants:v ^ 2)` = 5500.0 (100 + 400 + 900 + 1600 + 2500)

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
