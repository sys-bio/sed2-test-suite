# Test 00082

A dictionary constant used in math keeps its keys as labels.  d = {a: 1, b: 2, c: 3}, e = {a: 10, b: 20, c: 30}.

## Expected results

- `scaled`: `#constants:d * 10` = [10.0, 20.0, 30.0] (labels a, b, c are kept)
- `summed`: `#constants:d + #constants:e` = [11.0, 22.0, 33.0] (same keys: entries with the same key combine)

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
