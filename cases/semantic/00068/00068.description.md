# Test 00068

Arithmetic with NaN and infinity follows IEEE rules.

## Expected results

- `n1`: `notanumber + 1` = nan
- `n2`: `notanumber * 0` = nan
- `i1`: `infinity + 1` = inf
- `i2`: `infinity - infinity` = nan (undefined)
- `i3`: `1 / infinity` = 0.0
- `i4`: `infinity * -1` = -inf
- `i5`: `0 * infinity` = nan (undefined)
- `i6`: `infinity * infinity` = inf
- `i7`: `-infinity - 1` = -inf

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
