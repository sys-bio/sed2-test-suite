# Test 00234

removeElements: removing the reaction J1 from a chain -> S1 -> S2 -> .  The original is simulated for comparison.

## Expected results

Original: S1' = 2 - 0.5 S1 gives S1 = 4 - 3 exp(-t/2); S2' = 0.5 S1 - S2 gives S2 = 2 - 3 exp(-t/2) + 1.5 exp(-t).  Without J1 nothing converts S1: S1' = 2, S1 = 1 + 2 t, and S2' = -S2 gives S2 = 0.5 exp(-t).

## Sign-off

- Expected results: derived by hand (see above), not taken from a simulator.
- Tolerances: the defaults (absolute 1e-7, relative 1e-4).
- Backends: roadrunner, copasi, opencor (agree within the tolerances; admitted 2026-10-09 by the suite runner).
