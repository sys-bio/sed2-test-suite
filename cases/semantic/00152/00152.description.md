# Test 00152

Steady state of a source feeding a two-step chain: -> A at rate 2, A -> B at rate A, B -> at rate B/2.

## Expected results

dA/dt = v - k1 A = 0 gives A = v/k1 = 2; dB/dt = k1 A - k2 B = 0 gives B = k1 A/k2 = 4.  The result is a vector labelled by the output variables.  The starting values (1, 1) do not matter for this linear model.
